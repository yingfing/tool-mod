# Phantom Staff

纯客户端 Minecraft（NeoForge 1.21.1）辅助模组，专门针对 **Create Aeronautics**（modid `simulated`）的物理结构提供可视化与操作辅助：

- **高亮**：给每个已加载的物理结构（飞行载具/物理方块）画发光轮廓框，远距离/小目标也能定位。
- **追踪红线**：从你的眼睛向所有已加载的物理结构画红线——不要求瞄准、不要求进视锥、不要求被渲染；可穿透地形。
- **屏幕边缘箭头**：屏幕外或背后的结构在屏幕边缘画指向箭头，绝不漏标。
- **幽灵法杖槽位（核心）**：按一下热键就把 `simulated:creative_physics_staff` 物理法杖**换到手上**，再按一下换回。**发的是真实数据包，服务端也认可你确实拿着法杖**，因此左键固定 / 右键拖拽 / 滚轮 / Tab 全部生效，且不会被服务端以 `Invalid packet` 踢下线。
- **配置入口**：在游戏内「Mods」界面点本模组 → Config，或按 `G` 键直接打开配置菜单。

> 本模组只做客户端层面改动：**不伪造第 10 格**（选中格始终落在合法的 0–8 内），**不向服务器上报任何伪造数据包**，因此不会被反作弊以「invalid hotbar」踢出。切到手上的法杖是在**背包里真实存在**的那把，服务端全程认可。

## 环境 / 依赖矩阵

| 组件 | 版本要求 | 说明 |
|---|---|---|
| Minecraft | `1.21.1` | 固定版本 |
| NeoForge | `21.1.219+` | `loaderVersion="[4.0,)"` |
| Create | `6.0.10+` | 必需，客户端 |
| Create Aeronautics | `1.0+` | modid `simulated`，必需，客户端 |
| MaFgLib | `0.4.3+` | **客户端必需**，提供配置菜单（仅编译期依赖，游戏内需另行安装）|

> 上述四项在 `META-INF/neoforge.mods.toml` 中声明为 `required`（side=CLIENT）。缺少 MaFgLib 时配置菜单无法打开；缺少 Create / Aeronautics 时高亮与红线不会生效（模组仍可加载）。

## 安装

1. 安装匹配版本的 NeoForge、Create、Create Aeronautics、MaFgLib（客户端）。
2. 把本模组的 jar 放入 `.minecraft/mods/` 并启动游戏。

## 使用

1. **打开配置**：游戏内按 `Esc` → `Mods` → 找到 **Phantom Staff** → `Config`；或直接按 `G` 键。
   - 配置保存在 `config/phantomstaff.json`，所有开关均可在菜单内调整。
2. **追踪红线 / 高亮 / 边缘箭头**：在配置菜单「追踪红线」分类里直接开关 **`target_line_enable`**（**默认关闭**，装了模组不会突然冒出红线），开启后对所有已加载物理结构生效。**不需要绑定任何按键**——配置项本身就在界面里可视化更改。相关子项：
   - `toggle_target_line`：可选的热键快捷方式（默认未绑定），绑了可以快速切换红线开关
   - `target_line_color` / `target_line_width`：红线颜色与线宽
   - `target_line_max_distance`：最大追踪距离（方块）
   - `target_line_through_walls`：是否穿透地形
   - `target_line_edge_arrows`：屏幕边缘指向箭头
   - `target_line_highlight`：物理结构包围盒高亮框

3. **幽灵法杖槽位**：在配置菜单中确保 `enable_phantom_slot` 开启（默认开），并在「幽灵法杖槽位」分类下查看/修改热键。
   - 按 `B`（默认）把法杖换到手上，**再按一次换回原物品**。按一下即切换，**不需要按住**。
   - 切换方式按优先级自动选择，**全部是服务端认可的真实数据包**：
     1. 快捷栏其他格有法杖 → 发 `ServerboundSetCarriedItemPacket` **把选中格切到法杖那一格**（仍在 0–8 内，换回时会切回你原来的格子）
     2. 主背包里有法杖 → 发 `ServerboundContainerClickPacket(SWAP)` 把法杖**交换到当前手上**（仅在打开的是玩家自己的物品栏时执行）
     3. 背包里也没有 → 退化为本地生成（**仅客户端，服务端不认可**），游戏内会弹警告
   - ⚠️ **生存模式请把一把 `creative_physics_staff` 放在快捷栏或背包里**，否则会走第 3 条，左键固定结构可能被服务端踢下线。
   - ⚠️ 法杖放在**主背包**时，若你正打开着箱子/熔炉等外部容器界面，模组会**拒绝交换并提示**（此时槽位编号指的是容器的格子，发包会造成物品错乱）。关掉界面再按一次即可。
   - 💡 因此**最省心的做法是把法杖常驻快捷栏**：走 `SetCarriedItem`，不受容器界面影响，也最不容易被服务端拒绝。
   - 拿到法杖后（`PhysicsStaffItem.isHolding` 判定通过），Aeronautics 的**原生法杖操作全部生效**——这些是 Aeronautics 自带键位，不在本模组配置里：

     | 操作 | 效果 |
     |---|---|
     | 右键 | 开始拖拽（START_DRAG）当前瞄准的物理结构 |
     | 左键 | 法杖主功能（onItemPunched / 锁定相关） |
     | 移动鼠标 | 拖拽中改变结构朝向 |
     | **按住 `Tab` + 移动鼠标** | **旋转模式**：拖拽中旋转结构（Aeronautics 键位 `Physics Staff Rotate Mode`，默认就是 Tab） |
     | 滚轮 | 调整拖拽距离（按住疾跑键 ×4 加速） |

     > `Tab` 生效的两个前提：**① 必须先在拖拽中**（先右键 START_DRAG）；**② 按住** Tab 配合鼠标移动连续旋转，不是"按一下转固定角度"。若 Tab 与 Minecraft 默认的「玩家列表」键冲突，可在 选项 → 控制 里改 `Physics Staff Rotate Mode` 的键位。

### 为什么必须发真实数据包

Create Aeronautics 服务端在收到法杖操作包时会先过一道 `validateWorthyness`：检查**服务端眼里**玩家主手/副手是否真的是物理法杖，不是就 `disconnect("Invalid packet")` **直接踢下线**。这道闸从早期版本就存在（不是新加的）。

所以**纯客户端改物品栏的"幽灵法杖"是死路**：服务端权威地持有你的背包状态，客户端怎么改都骗不过它。

本模组因此改用**原版网络包真实切换**——让服务端也认可你确实拿着法杖，左键固定 / 右键拖拽 / 滚轮 / Tab 才能全部生效且不会被踢。本模组不绕过任何校验，只是帮你把法杖合法地换到手上。

> 顺带一提：Create: Cyber Goggles 也内置了同类功能（`usePhysicsStaff` 热键），但它是**按住**模式（松开立刻换回），且不占用额外键位时不可用。本模组做的是**按一下切换、按一下换回**，更适合左手键位已经排满的情况。

## 构建

GitHub Actions 自动构建：推送到 `1.21.1` 分支即触发，产物 jar 在 Actions 页面的 Artifacts 中下载。
打 `v*` 开头的 Tag（如 `v1.14.0`）会额外自动创建 GitHub Release 并附上 jar。

> **版本号软编码**：版本号由构建脚本从 git tag 自动推导——当前提交指向某个 `v*` tag 时直接用该 tag 作版本；分支/提交（未打 tag）构建则形如 `1.13.0-dev.a1b2c3d4`。**发版只需 `git tag vX.Y.Z && git push origin vX.Y.Z`，无需改任何文件。**

本地构建：

```bash
./gradlew build          # 产物位于 build/libs/*.jar
./gradlew runClient      # 本地带模组的客户端调试（需先装好依赖模组）
```

## 已知限制 / Roadmap

- 仅支持 Minecraft 1.21.1 / NeoForge 21.1.x。
- 红线/高亮/边缘箭头依赖 Aeronautics 已把物理结构下发到客户端（即你已加载对应维度）。
- 幽灵法杖依赖你**背包里真的有法杖**（快捷栏或主背包）。背包里没有时会退化为纯客户端本地生成，此时服务端不认可，**左键固定结构可能被踢下线**——游戏内会弹警告提醒你。
- 生存模式下主背包交换依赖 `ServerboundContainerClickPacket`，若服务端反作弊对容器点击包做严格校验，可能失败；此时**把法杖放在快捷栏**（走 `SetCarriedItem`，最稳）。
- 切换状态是客户端记忆的：若中途被服务端刷新物品栏（跨维度、死亡复活、管理员改动背包等），再按一次切换键即可自愈（模组会重新识别并重新切换）。
- 未安装 Create Aeronautics 时启动日志会提示「未检测到物理法杖物品」，幽灵槽位不可用，其余功能不受影响。
